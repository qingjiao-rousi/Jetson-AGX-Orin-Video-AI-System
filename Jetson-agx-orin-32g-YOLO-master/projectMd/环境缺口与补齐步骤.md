# 环境缺口与补齐步骤

## 当前已经具备

- DeepStream SDK 7.1.0 已安装。
- TensorRT runtime/dev 已安装，版本为 10.3。
- GStreamer 基础组件可用。
- `nvinfer`、`nvtracker`、`nvdsosd`、`nvvideoconvert`、`nvv4l2decoder` 可用。
- `nvstreammux` 已存在，但需要加载 DeepStream 插件路径。

## 当前缺口

1. `pyds` 缺失。
   - 现象：`ModuleNotFoundError: No module named 'pyds'`
   - 影响：Python 侧无法读取 DeepStream metadata。

2. `nvcc` 缺失。
   - 现象：`bash: nvcc: 未找到命令`
   - 影响：无法编译自定义 CUDA/C++ parser 或相关扩展。

3. `trtexec` 缺失。
   - 现象：`bash: trtexec: 未找到命令`
   - 影响：无法从 ONNX 生成 TensorRT engine。

4. 项目模型资源缺失。
   - `models/yolov8n.engine`
   - `models/labels.txt`
   - `custom_libs/nvdsinfer_custom_impl_Yolo/libnvdsinfer_custom_impl_Yolo.so`

## 先加载项目环境变量

每次打开新终端后，先执行：

```bash
cd /home/nvidia/Desktop/YOLO/Jetson-agx-orin-32g-YOLO-master
source scripts/env.sh
```

之后再检查：

```bash
bash scripts/check_env.sh
```

## 安装系统依赖和 pyds

推荐直接执行：

```bash
cd /home/nvidia/Desktop/YOLO/Jetson-agx-orin-32g-YOLO-master
bash scripts/install_jetson_deps.sh
```

这个脚本会安装：

- `cuda-nvcc-12-6`
- `libnvinfer-bin`
- Python/GStreamer 开发依赖
- 项目 Python 基础依赖
- 从 NVIDIA `deepstream_python_apps` 的 `v1.2.0` tag 构建并安装 `pyds`

注意：不要直接使用 `deepstream_python_apps` 的 master 分支。当前 master 只允许 Python 3.12，而 JetPack 6 / Ubuntu 22.04 默认是 Python 3.10，会报：

```text
PYTHON_MINOR_VERSION must be one of 12
```

如果已经遇到这个错误，执行：

```bash
cd /home/nvidia/Desktop/YOLO/Jetson-agx-orin-32g-YOLO-master
bash scripts/install_jetson_deps.sh
```

脚本会自动切到兼容 Python 3.10 的 `v1.2.0`。

## 安装后验证

```bash
source scripts/env.sh
bash scripts/check_env.sh
```

关键项应通过：

```bash
python3 -c "import pyds; print('pyds OK')"
nvcc --version
trtexec --version
gst-inspect-1.0 nvstreammux
```

## 生成模型资源

环境补齐后再执行：

```bash
source scripts/env.sh
bash scripts/download_models.sh
```

该脚本会生成/准备：

- `models/yolov8n.pt`
- `models/yolov8n.onnx`
- `models/yolov8n.engine`
- `models/labels.txt`

YOLO DeepStream 自定义 parser `.so` 仍需要单独补齐或编译。

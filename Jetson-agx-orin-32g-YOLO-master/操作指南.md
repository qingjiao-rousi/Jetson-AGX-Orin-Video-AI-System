# 一、格式化SSD固态硬盘，先让其恢复到最初拿到手时的状态，不进行分区

## Windows 上格式化（用 diskpart）

1. SSD 通过硬盘盒连接到 Windows 电脑。
2. 右键点开始菜单 → **Windows PowerShell (管理员)** 或 **命令提示符 (管理员)**。
3. 输入以下命令：

```
diskpart
list disk
```

4. 假设是 `磁盘 0`，然后**逐条执行**：

```
select disk 1
clean
convert gpt
create partition primary
format fs=ntfs quick
assign letter=Z
```

5. 格式化完成后，**最重要的一步**——再次执行：

```
select disk 1
clean
```

这次 `clean` 之后，**什么都不要再做**，不要创建分区，不要格式化。

6. 退出：

```
exit
```

# 二 、刷机

## 第一步：进入工作目录并确认文件

```
cd ~/nvidia/nvidia_sdk/JetPack_6.2_Seeed
ls -la
```

你应该看到三个压缩包：

* `Jetson_Linux_R36.4.3_aarch64.tbz2`
* `Tegra_Linux_Sample-Root-Filesystem_R36.4.3_aarch64.tbz2`
* `605_jp62.tar.gz`

```

tar xf Jetson_Linux_R36.4.3_aarch64.tbz2

sudo tar xfp Tegra_Linux_Sample-Root-Filesystem_R36.4.3_aarch64.tbz2 -C Linux_for_Tegra/rootfs
```

## 第三步：安装刷机依赖并应用二进制文件

```
cd Linux_for_Tegra

sudo ./tools/l4t_flash_prerequisites.sh

# 应用根文件系统二进制文件
sudo ./apply_binaries.sh
```

## 第四步：解压 Seeed 外设驱动并覆盖

```
cd ..

# 解压 Seeed 外设驱动包
tar xf 605_jp62.tar.gz

# 将 Seeed 定制的文件覆盖到 Linux_for_Tegra 目录
sudo cp -r 605_jp62/Linux_for_Tegra/* Linux_for_Tegra/
```

## 第五步：确认开发板处于 Recovery 模式

```

### 下载`deepstream_python_apps-1.2.0`

#### 📦 第一步：安装系统依赖包

在编译之前，需要确保所有必要的开发工具和库都已安装。在终端中执行：

```

    python3-gi python3-dev python3-gst-1.0 python-gi-dev \
    git meson python3-pip python3.10-dev cmake g++ build-essential \
    libglib2.0-dev libglib2.0-dev-bin libgstreamer1.0-dev \
    libtool m4 autoconf automake libgirepository1.0-dev libcairo2-dev
```

#### 🔨 第二步：编译并安装 `pyds`

进入你下载的源码目录，并执行编译流程：

```
# 1. 进入源码目录
cd ~/下载/deepstream_python_apps-1.2.0

# 2. 初始化子模块 (这一步会拉取依赖的 gst-python 等源码)
git submodule update --init

# 3. 进入 pyds 绑定目录并创建构建目录
cd bindings
mkdir build && cd build

# 4. 使用 CMake 配置 (关键：正确指定 Python 版本和 DeepStream 路径)
cmake .. \
    -DPYTHON_MAJOR_VERSION=3 \
    -DPYTHON_MINOR_VERSION=10 \
    -DPIP_PLATFORM=linux_aarch64 \
    -DDS_PATH=/opt/nvidia/deepstream/deepstream-7.1/

# 5. 开始编译 (使用 -j 参数加速)
make -j$(nproc)
```

#### ✅ 第三步：安装生成的 Wheel 包

编译完成后，你会在当前目录 (`bindings/build/`) 下看到一个 `.whl` 文件。使用 pip 安装它：

```
# 安装生成的 wheel 包
sudo pip3 install ./pyds-*.whl
```

#### 🔍 第四步：验证安装

最后，运行以下命令验证 `pyds` 模块是否能被 Python 成功导入：
